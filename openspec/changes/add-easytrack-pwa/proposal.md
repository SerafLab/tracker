# Proposal

## Why

Текущая доска хранит проекты локально, но остаётся обычной вкладкой: её нельзя надёжно установить как самостоятельное приложение и повторно открыть без сети. EasyTrack должен завершить согласованный mobile-first local-first сценарий на GitHub Pages, не создавая ложного обещания, что браузерное хранилище заменяет резервную копию.

## What Changes

- Добавить PWA-метаданные, локальные иконки и standalone-идентичность приложения **EasyTrack** для пути `/tracker/`.
- Добавить service worker, который предварительно кеширует только production app shell и локальные assets, чтобы установленное приложение после первой онлайн-загрузки открывалось и работало без сети.
- Добавить ненавязчивую доступную подсказку установки и постоянный путь к ней; на iPhone/iPad объяснить установку до создания первых проектов.
- Предлагать доступное обновление только после готовности новой версии и активировать его исключительно по явному подтверждению пользователя; не прерывать работу автоматически.
- Безопасно обрабатывать устаревшую вкладку при смене IndexedDB: прекратить редактирование, закрыть старое соединение и предложить перезапуск.
- После осмысленного пользовательского действия неблокирующе запрашивать persistent storage и ясно объяснять, что оно не защищает от ручной очистки данных.
- Добавить browser-level проверки manifest, service worker, офлайн-повторного запуска и подтверждаемого обновления в Chromium, а также release checklist для реальных iPhone/Safari и Android.
- Зафиксировать, что Safari и установленный iOS/iPadOS web app имеют изолированные локальные хранилища: автоматический перенос проектов из Safari в установленный EasyTrack не добавляется.

## Capabilities

### New Capabilities

- `offline-installed-app`: Установка EasyTrack, офлайн-доступность app shell, контролируемые обновления, защита локального хранилища и проверка PWA-сценариев.

### Modified Capabilities

Нет.

## Impact

- Затрагиваются `vite.config.ts`, `package.json` и lockfile, `index.html`, точка входа и presentation-слой React, статические manifest/icon assets, а также сборка и browser-level тесты.
- Добавляется `vite-plugin-pwa` с Workbox в режиме `generateSW` и браузерный тестовый runtime для Chromium; GitHub Pages продолжает публиковать только статический `dist` по `/tracker/`.
- Текущая IndexedDB schema v1, модель проектов, хеш-навигация и данные пользователя не меняются. Сервер, аккаунты, синхронизация, автоматический перенос данных между Safari и iOS web app, backup/export/import и runtime-кеширование сторонних ресурсов не входят в change.
