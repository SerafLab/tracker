# Proposal

## Why

Пользователь может создавать проекты, но не может убрать ненужный проект. Удаление проекта целиком позволит очистить каталог без ручного удаления каждой карточки и статуса.

## What Changes

- Добавить «Удалить проект» в меню проекта в каталоге и настройки его открытой доски.
- Перед удалением показать название, количество статусов и карточек, предупреждение о необратимости и кнопки «Отмена» / «Удалить проект»; начальный фокус — на отмене, ввод названия не требуется.
- Окончательно удалять выбранный по ID проект со всеми статусами и карточками одной транзакцией; при ошибке сохранять данные и диалог для повторной попытки.
- После удаления открытого проекта возвращать каталог, очищать ссылку на удалённый последний проект; при удалении последнего проекта показывать существующее пустое состояние.
- Обеспечить доступность с клавиатуры и мобильного экрана, тексты на русском и английском.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `project-boards`: подтверждённое каскадное удаление проекта, сохранение результата, обработка ошибок и навигация.
- `application-shell`: удаление текущего проекта из настроек доски и взаимодействие панели с подтверждением.

## Impact

- Порт репозитория, use cases, Dexie, Zustand и представления `src/features/project-board`; навигация `src/app/app.tsx`, общий `src/ui/app-bar.tsx`, переводы и тесты.
- Новые библиотеки и изменение схемы IndexedDB для текущей модели не нужны.
- Незавершённый `add-agent-mcp-integration` не получает инструмент удаления проектов. При совместной реализации согласовать общий репозиторий и обновление отсутствующего проекта.
- `add-card-details` планирует заметки карточек и меняет AppBar/навигацию: если заметки внедрены раньше, включить их в каскад и транзакцию; при обратном порядке расширение каскада относится к внедрению заметок. Изменение не зависит от наличия заметок.
- Вне объёма: корзина, восстановление, архивирование, массовое удаление, сервер и синхронизация. Код и основные спецификации не изменяются на этапе предложения.
