# Spec Delta

## ADDED Requirements

### Requirement: Restore while signed in
Восстановление при выполненном входе SHALL быть доступно. Диалог сравнения SHALL дополнительно предупреждать, что копия заменит данные проектов на всех устройствах аккаунта. После замены удалённые записи SHALL удаляться, а записи копии — появляться на других устройствах аккаунта после синхронизации.

#### Scenario: User restores while signed in
- **WHEN** пользователь с выполненным входом выбирает корректную копию
- **THEN** диалог сравнения содержит предупреждение о замене данных на всех устройствах аккаунта

#### Scenario: Other device receives the restored data
- **WHEN** пользователь подтвердил восстановление на телефоне, а компьютер того же аккаунта в сети
- **THEN** компьютер показывает только проекты из копии

### Requirement: Backup contains only project data
Выгрузка SHALL записывать только поля данных проектов в формате текущей версии, без служебных полей синхронизации и без записей, чьи владельцы удалены. Копия, выгруженная с выполненным входом, SHALL восстанавливаться на устройстве без входа и наоборот.

#### Scenario: Export while signed in
- **WHEN** пользователь с выполненным входом выгружает копию и восстанавливает её на другом устройстве без входа
- **THEN** копия проходит проверку и восстанавливает те же проекты, карточки и заметки
