# Статическое local-first приложение на GitHub Pages

Веб-MVP реализуется как статическое SPA на React, TypeScript и Vite без серверной части, авторизации и синхронизации; пользовательские данные хранятся в браузере, а файлы приложения кешируются для установленной офлайн-работы. Публичный репозиторий `SerafLab/tracker` публикуется через GitHub Actions на постоянный GitHub Pages-origin `https://seraflab.github.io/tracker/`: это минимизирует инфраструктуру первого учебного цикла, но оставляет данные независимыми для каждого браузера и устройства и делает будущую смену origin отдельной задачей переноса данных.
