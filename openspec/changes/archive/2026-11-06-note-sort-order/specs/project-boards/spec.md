# Spec Delta

## MODIFIED Requirements

### Requirement: Expand recent notes independently
Если у карточки больше одной заметки, система SHALL предоставлять отдельную доступную кнопку раскрытия. Раскрытая карточка SHALL показывать не более пяти последних заметок, включая первоначально видимую, в порядке, выбранном пользователем для истории заметок (по умолчанию от новых к старым); каждая SHALL занимать не более трёх строк. Повторное нажатие SHALL сворачивать список до одной последней заметки. Кнопка SHALL не открывать страницу карточки и не мешать её остальным контролам.

#### Scenario: Card has between two and five notes
- **WHEN** пользователь раскрывает карточку с четырьмя заметками
- **THEN** видны все четыре заметки в выбранном порядке по дате создания, без повтора последней

#### Scenario: Card has more than five notes
- **WHEN** пользователь раскрывает карточку с шестью или более заметками
- **THEN** видны только пять последних, а вся история доступна на странице карточки

#### Scenario: User collapses notes
- **WHEN** пользователь повторно нажимает кнопку раскрытия
- **THEN** остаётся только последняя заметка и кнопка показывает свёрнутое состояние

#### Scenario: Keyboard user expands notes
- **WHEN** пользователь активирует кнопку клавиатурой на узком экране
- **THEN** список раскрывается без перехода на страницу карточки, состояние кнопки и её назначение доступны вспомогательным технологиям, а ссылка на карточку, меню карточки и перетаскивание остаются доступны

#### Scenario: User returns after note changes
- **WHEN** пользователь добавляет, изменяет или удаляет заметку на странице карточки и возвращается на доску
- **THEN** предпросмотр и состав последних пяти отражают только сохранённую историю этой карточки

#### Scenario: Expanded notes follow the default order
- **WHEN** пользователь, ещё не выбиравший порядок, раскрывает карточку с тремя заметками
- **THEN** самая новая заметка показана первой, на том же месте, где она была видна в свёрнутом состоянии

#### Scenario: User changes the order while the board is visible
- **WHEN** на широком экране пользователь переключает порядок в панели карточки при раскрытых заметках другой карточки на доске
- **THEN** раскрытый список на доске сразу показывается в новом порядке, а свёрнутые карточки по-прежнему показывают одну самую новую заметку
