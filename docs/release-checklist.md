# PWA release checklist

Выполняйте после публикации EasyTrack на GitHub Pages. До первого пункта
откройте именно опубликованный URL и установите приложение: проверка Safari в
браузерной вкладке не заменяет проверку установленного web app.

## iPhone / Safari

- [ ] Записаны модель устройства, версия iOS и версия Safari в release record ниже.
- [ ] Через **Поделиться → На экран «Домой»** установлен EasyTrack до создания тестовых проектов.
- [ ] Онлайн созданы тестовый проект, статус и карточка; после закрытия приложения они видны при повторном открытии без сети.
- [ ] Без сети создано или изменено ещё одно значение; после второго офлайн-перезапуска изменение сохранено.
- [ ] После появления обновления выбрано «Позже»: приложение не перезагрузилось. Затем выбрано «Обновить»: новая версия открылась.
- [ ] Подтверждено, что проекты Safari не переносятся автоматически в установленную иконку; это не трактуется как потеря данных.
- [ ] В Safari выгружена резервная копия (**Выгрузить резервную копию**): открылось системное меню «Поделиться» или файл скачался; файл сохранён в «Файлы».
- [ ] В установленном приложении выбрано **Восстановить из резервной копии**: сохранённый файл `.json` выбирается, диалог сравнения показывает числа и дату копии, после «Заменить» открылся каталог с проектами из Safari.
- [ ] В установленном приложении выгрузка также открывает «Поделиться» или скачивает файл; если пользователь закрыл меню «Поделиться» без выбора, сообщения об ошибке нет.

## Android / Chrome

- [ ] Записаны модель устройства, версия Android и версия Chrome в release record ниже.
- [ ] EasyTrack установлен из Chrome до создания тестовых проектов.
- [ ] Пройден сценарий online create → offline reopen → offline change → offline reopen.
- [ ] Пройден сценарий deferred update, затем explicit update.
- [ ] Выгружена резервная копия, данные изменены, копия восстановлена из выбранного файла; проекты, порядок, описания и заметки с датами совпали с выгруженными.

record означает, что физическая мобильная приёмка не завершена, если только
владелец проекта явно не принял проверку без метаданных устройств.
