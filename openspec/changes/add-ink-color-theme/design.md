# Design

## Context

- Палитра задана custom properties в `:root` файла `src/styles.css`. Через токены идёт только часть цветов. Ещё около 15 значений с зелёным оттенком захардкожены: рамки hover `#a5b3a7`, рамка поля `#aeb9af`, выделение `#cbe2d1`/`#193126`, tap highlight, маркер перетаскивания `#e3ece4`, скелетон `#e3e7de`, скроллбар `#9aaa9c`, disabled-текст `#838b81`, тень `rgb(18 39 30 / 14%)`, фолбэк `#cfd8d0`. Похожие цвета есть и в dev-пробе `src/dev/dnd-sensor-probe.css`.
- Предпочтение языка устроено так: `src/i18n/locale.ts` хранит ключ `easytrack.locale` в `localStorage` и защищает чтение от ошибок; `src/i18n/provider.tsx` даёт контекст с `select` и `warning`; `LocaleSelector` — нативный `<select>`, который вставлен в панель настроек в `src/ui/app-bar.tsx`. Требования к выбору темы те же, поэтому повторяем этот паттерн.
- Приложение статичное: Vite, PWA, без сервера. CSS подключается в `<head>`, приложение — module script с отложенным выполнением, поэтому браузер может нарисовать страницу до запуска React.

## Goals / Non-Goals

**Goals:**
- Тема переключается одним атрибутом на `<html>`, без перезагрузки и без JS-перекраски компонентов.
- Все цвета из области темы (спека `color-theme`, «Theme scope») берутся только из токенов.

**Non-Goals:**
- Автоматический вывод палитры из акцента в рантайме.
- Общий механизм для произвольного числа тем: вторая тема — это блок переопределений, третья добавляется так же.

## Decisions

### 1. Токены: зелёные значения по умолчанию, Ink — переопределения по атрибуту

`:root` хранит значения темы Green. `:root[data-theme="ink"]` переопределяет только токены из области темы. Общие цвета (`--canvas`, `--surface`, `--field`, `--danger*`, цвета меток) не переопределяются. Захардкоженные значения переносятся в новые токены, например `--border-strong`, `--field-border`, `--selection-bg`, `--selection-text`, `--tap-highlight`, `--marker-bg`, `--skeleton`, `--scrollbar`, `--text-disabled`, `--shadow-color`. Окончательные имена выбирает исполнитель, но правило одно: внутри области темы в правилах нет литеральных цветов.

Значения Ink посчитаны в OKLCH: яркость и относительная хрома как у соответствующего зелёного токена, тон 255° акцента `#2d496d`. Hover и focus сдвинуты от акцента на ту же разницу яркости, что у зелёной темы:

| Токен | Green | Ink |
|---|---|---|
| `--accent` | `#315f48` | `#2d496d` |
| `--accent-hover` | `#244d38` | `#1f3858` |
| `--focus` | `#22744c` | `#275793` |
| `--text` | `#26372e` | `#283342` |
| `--text-secondary` | `#516157` | `#525d6c` |
| `--text-muted` | `#67716a` | `#676f79` |
| `--border` | `#d9ddd4` | `#d5dce5` |
| `--surface-subtle` | `#e7ece3` | `#e4ebf4` |
| рамка hover | `#a5b3a7` | `#a4b0bf` |
| выделение фон / текст | `#cbe2d1` / `#193126` | `#cbddf4` / `#1d2c3f` |
| маркер | `#e3ece4` | `#e2eaf4` |
| скелетон | `#e3e7de` | `#dfe6ef` |

Значения для `--field-border`, скроллбара, disabled-текста, tap highlight и тени выводятся тем же способом при реализации. Контраст на рабочем фоне `#f5f4f0` и поверхности `#fffefa` проверен: у Ink текст 11.6 / 12.7, вторичный 6.1 / 6.6, приглушённый 4.6 / 5.0, белый на акценте 9.2, на hover 11.9, focus 6.7 / 7.3; у Green эти значения не меньше. Приглушённый текст на `--surface-subtle` в обеих темах ниже 4.5 (4.2). Сейчас такого сочетания нет: quiet-кнопка при hover переключает текст на `--text`. Его нельзя вводить и дальше.

Альтернативы: отдельный CSS-файл на тему даёт лишний запрос и вспышку при переключении; CSS relative color `oklch(from var(--accent) ...)` выводит палитру автоматически, но требует свежих браузеров, и контраст получившихся значений нельзя проверить заранее. Явные hex проще проверить и описать в `DESIGN.md`.

### 2. Применение до первой отрисовки — inline-скрипт в `<head>`

Маленький классический inline-скрипт в `index.html`, до подключения CSS. Он читает `localStorage['easytrack.theme']` в `try/catch` и ставит `data-theme="ink"` только при точном совпадении. Любое другое значение или ошибка оставляют Green. Скрипт синхронный, поэтому первый кадр, включая экран загрузки, уже в нужной теме.

Альтернатива — ставить атрибут в `main.tsx`. Модуль выполняется после разбора документа, и Ink-пользователь мог бы увидеть зелёный кадр. Ключ дублируется в `index.html` и модуле темы. Чтобы они не разошлись, unit-тест сверяет ключ в `index.html` с экспортируемой константой.

### 3. Состояние и выбор — `ThemeProvider` по образцу `LocaleProvider`

Модуль темы в `src/ui/` (вне `features/project-board`, архитектурные правила не затрагиваются) содержит:
- тип `ColorTheme = 'green' | 'ink'`, ключ хранения, `resolveTheme(storage)` с откатом на `green`;
- провайдер: начальное состояние читается из атрибута `<html>`, уже выставленного скриптом. `select(theme)` ставит атрибут (для green атрибут снимается) и пишет в `localStorage`. При ошибке записи `warning = true`, тема при этом остаётся применённой;
- `ThemeSelector` — нативный `<select>` с подписью «Цветовая тема приложения» и опциями «Зелёная» и «Чернильная», плюс `role="alert"` с предупреждением. Стили и разметка как у `LocaleSelector`. Рендерится в панели настроек сразу после `LocaleSelector`.

`ThemeProvider` оборачивает приложение в `App` рядом с `LocaleProvider`. Тексты в `src/i18n/resources.ts`: `colorTheme`, `themeGreen`, `themeInk`, `themePreferenceWarning`. Предупреждение отдельное от языкового, потому что в нём говорится о теме.

Альтернатива — образцы-свотчи в виде radio group. Они нагляднее, но это новый компонент со своей клавиатурной моделью, а нативный select уже проверен в этой панели. Свотчи можно добавить позже, требования к выбору не изменятся.

### 4. Тесты

- Unit: `resolveTheme` (нет значения, неизвестное значение, ошибка чтения); выбор применяет атрибут и пишет ключ; ошибка записи показывает предупреждение и оставляет тему; селектор есть только в открытых настройках; подписи на обоих языках; ключ в `index.html` совпадает с константой.
- E2E: выбор Ink на доске меняет вычисленный `background-color` плюса создания без перезагрузки; после `page.reload()` и на другом проекте Ink сохраняется; с `localStorage` в Ink до загрузки первый кадр (экран загрузки) уже имеет атрибут. Существующий тест цвета фона липкого заголовка (`calm-board.spec.ts`) остаётся неизменным: фон общий.
- Визуальная проверка по `docs/agents/rules/visual-review.md`: доска и каталог в Ink на 390 и 1440 px (hover, фокус, маркер перетаскивания, ошибка), панель настроек на 320 px с двумя селекторами и предупреждением.

## Risks / Trade-offs

- [Пропущенный захардкоженный зелёный оставит в Ink зелёные следы] → после выноса в токены проверять поиском, что в `src/styles.css` вне блоков тем нет литеральных цветов из области темы; e2e-сценарий «No green remains in Ink» на ключевых состояниях.
- [Inline-скрипт и ключ живут вне TypeScript] → тест сверки ключа; скрипт минимален и не имеет зависимостей.
- [Две строки настроек занимают больше места на 320 px] → проверить высоту панели; она уже прокручивается (`max-height` + `overflow: auto`).
- [`theme_color` в манифестах (`#0F766E`) не совпадает ни с одной темой] → вне объёма (см. proposal), отдельное исправление.

## Migration Plan

Миграции данных нет: отсутствие ключа означает Green, текущие пользователи ничего не замечают. Откат — revert изменения; оставшийся в хранилище ключ `easytrack.theme` игнорируется.
