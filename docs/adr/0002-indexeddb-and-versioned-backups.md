# IndexedDB, forward-only миграции и версионированные резервные копии

Пользовательские данные хранятся в нормализованных хранилищах IndexedDB через Dexie и доступны интерфейсу только через репозиторный слой. Схема мигрирует только вперёд и транзакционно, а резервная копия представляет собой проверяемый Zod версионированный JSON, который при подтверждённом восстановлении атомарно заменяет текущие данные; merge и downgrade не входят в MVP. Дополнительная структура оправдана долговечностью реальных локальных данных, явными транзакциями и контролируемыми обновлениями, а цена решения — необходимость поддерживать миграции и невозможность считать откат файлов приложения откатом базы.
