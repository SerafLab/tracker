# Design

## Context

См. `proposal.md` и `specs/project-boards/spec.md`. Сейчас доска читает `ProjectBoard` без заметок, а `CardView` показывает название, признаки и меню (перемещение — перетаскиванием и через меню). Изменение `add-card-details` ещё не реализовано: оно добавит `Note`, страницу карточки, порядок истории по `createdAt` и `id`, а также предпросмотр описания на доске. Этот дизайн применяется после него и должен сохранить оба вида предпросмотра и самостоятельность контролов.

## Goals / Non-Goals

**Goals:** получать для доски только данные, нужные для краткого просмотра; оставлять историю заметок единой; сохранить открытие страницы всей свободной областью карточки и доступность кнопки раскрытия.

**Non-Goals:** хранить состояние раскрытия, добавлять или редактировать заметки с доски, менять порядок истории либо формат хранения.

## Decisions

### 1. Читать последние пять из существующего хранилища заметок

После выполнения `add-card-details` расширить чтение доски краткими данными заметок для каждой её карточки: до пяти записей в порядке `(createdAt, id)` от старой к новой. Репозиторий выбирает их через индекс `notes` по карточке и времени создания, ограничивая выборку пятью на карточку. Представление получает подтверждённые данные вместе с доской; оно не создаёт вторую копию истории и не меняет `Card` полями предпросмотра. При возврате со страницы карточки доска перечитывается, поэтому создание, правка и удаление заметки отражаются без отдельной синхронизации кэша.

Альтернативы: загружать полную историю каждой карточки или хранить текст последней заметки в `Card`. Первая масштабирует объём чтения с длиной истории, вторая требует синхронизировать дублированные данные при каждой операции. Отдельный набор кратких данных проще для доски.

### 2. Раскрытие — локальное состояние карточки

`CardView` по умолчанию показывает последний элемент полученного списка. При раскрытии показывает весь список из максимум пяти заметок без повторения последней; порядок совпадает со страницей карточки. Кнопка присутствует при двух и более заметках, имеет локализованную подпись, `aria-expanded` и связь с областью заметок. Состояние не сохраняется между открытиями доски. Если после перечитывания заметок осталось меньше двух, список сворачивается и кнопка исчезает.

Альтернатива — сохранять раскрытие в IndexedDB или общем состоянии доски. Это добавило бы долговременное состояние для временного просмотра без пользы для данных карточки.

### 3. Сохранить отдельные области действия и ограничить высоту текста

Заметки отображаются безопасным обычным текстом внутри области ссылки на страницу карточки. В превью нет вложенных веб-ссылок и элементов редактирования. Кнопка раскрытия — сосед ссылки, как меню, чтобы её активация не открывала страницу. Для каждой записи CSS ограничивает текст тремя визуальными строками, включая многострочный текст; длинные слова и URL переносятся. Предпросмотр описания из `add-card-details` сохраняется отдельно. Проверить фактическую высоту карточек и доступность элементов при 320/390 px и ширине доски с четырьмя статусами.

Альтернатива — делать всю карточку кнопкой и останавливать всплытие событий от внутренних контролов. Это нарушает семантику вложенных интерактивных элементов и усложняет клавиатурное управление.

## Risks / Trade-offs

- Запросы последних заметок для каждой карточки увеличивают число чтений доски → выбирать через индекс с лимитом, не загружать полные тексты всей истории; проверить доску с большим числом карточек.
- Раскрытые заметки и предпросмотр описания увеличивают высоту карточки → ограничить каждую запись тремя строками и проверить мобильные размеры без перекрытия меню и ссылки карточки.
- После изменения заметки на странице доска может показывать устаревший снимок → перечитывать подтверждённые данные при возврате и не обновлять превью до успешного сохранения.

## Migration Plan

Сначала завершить `add-card-details`, затем реализовать это изменение поверх его схемы заметок и маршрута карточки. Миграция IndexedDB не нужна. Откат интерфейсного изменения оставляет сохранённые заметки и страницу карточки работоспособными.
