# Proposal

## Why

При первом запуске каталог выглядит недоделанным: подзаголовок висит над карточкой пустого состояния, карточка прижата влево, и в ней нет действия — создать проект можно только через «+» в app bar. Пользователь хочет начать работу одним нажатием. По умолчанию приложение должно открываться в теме «Чернильная», а не «Зелёная».

## What Changes

- Пустой каталог показывает один блок: по центру по горизонтали и в оптическом центре по вертикали, с отступом, зависящим от высоты экрана. В блоке заголовок «Начните с первого проекта», основная кнопка «Создать проект» и место для ошибки сохранения. Карточки-подложки и поясняющего абзаца нет.
- Кнопка в блоке одним нажатием, без диалога, создаёт проект «Первый проект» / «First project» (название на языке интерфейса в момент создания) с набором статусов «Простой» и открывает его доску. При ошибке сохранения кнопка остаётся на месте, а под ней появляется сообщение.
- «+» в app bar остаётся основным способом создать проект и в пустом каталоге. Правило «единственного входа создания» получает исключение для быстрого создания — так же, как сейчас для применения набора статусов на пустой доске.
- Если каталог стал пустым после удаления проекта (из каталога или с доски), фокус переходит на кнопку в блоке, а не на «+».
- Фраза «Держите важные дела в понятном порядке.» удаляется из каталога на обоих экранах.
- **BREAKING** (поведение у существующих пользователей): тема по умолчанию — «Чернильная». Её получают все, кто тему явно не выбирал, а также при отсутствующем, нераспознанном или недоступном сохранённом значении. Явно выбранная «Зелёная» сохраняется.
- `theme_color` в веб-манифестах меняется на акцент Ink `#2d496d`.
- В `DESIGN.md` появляется раздел про каталог, тема по умолчанию меняется на Ink, исправляется размер h1 на телефоне. `PRODUCT.md` описывает быстрое создание первого проекта.

Вне объёма: значок приложения (`#0F766E` в `public/icons/easytrack-icon.svg`), порядок пунктов темы в настройках, рамка неактивных кнопок вне блока первого запуска, управление темой и быстрым созданием через агентские инструменты (WebMCP).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `project-boards`:
  - «Clear workspace interface states» — пустой каталог предлагает быстрое создание;
  - «Single primary creation entry in catalogue and board» — исключение для быстрого создания;
  - «Project deletion navigation and focus» — фокус на кнопке блока при пустом каталоге;
  - новое требование о составе, размещении и поведении блока первого запуска.
- `color-theme`: «Available color themes» — тема по умолчанию и тема при нераспознанном значении становятся Ink.

## Impact

- `src/features/project-board/presentation/project-catalogue-view.tsx` — блок первого запуска, быстрое создание, фокус; удаление подзаголовка.
- `src/features/project-board/presentation/project-board-app.tsx` — фокус после удаления проекта с доски попадает в новый блок через существующий `focusCreation`.
- `src/styles.css`:
  - стили блока;
  - удаление `.page-subtitle` и `.catalogue-subtitle`;
  - значения Ink переносятся в `:root`, Green становится переопределением `[data-theme="green"]`.
- `index.html`, `src/ui/theme.ts`, `src/ui/theme-provider.tsx` — Ink по умолчанию.
- `scripts/theme-contrast.check.mjs` — селекторы тем меняются местами.
- `public/manifest.ru.webmanifest`, `public/manifest.en.webmanifest` — `theme_color`.
- `src/i18n/resources.ts`:
  - новый ключ `firstProjectName`;
  - удаление `firstProjectHelp` и `subtitle`.
- Тесты:
  - `src/ui/theme.test.tsx`, `e2e/color-theme.spec.ts` — значение по умолчанию;
  - `e2e/project-deletion.spec.ts`, `src/features/project-board/presentation/project-deletion.test.tsx` — фокус;
  - новые тесты быстрого создания и размещения блока на эталонных размерах.
- `DESIGN.md`, `PRODUCT.md`. Новых зависимостей нет.
