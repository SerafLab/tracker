# Модульный монолит для доски проекта

Сценарий ведения проектов организован как feature-модуль `project-board` в модульном монолите: `app` создаёт зависимости и владеет hash-навигацией, а внутри feature направленные зависимости идут от React-представления и Zustand runtime-состояния к application use cases, domain и порту репозитория; Dexie остаётся реализацией этого порта. Zustand хранит только подтверждённое состояние работающего интерфейса, тогда как IndexedDB остаётся долговременным источником данных согласно [ADR-0002](0002-indexeddb-and-versioned-backups.md); сервер, синхронизация и мобильный runtime намеренно отложены, сохраняя local-first границы [ADR-0001](0001-static-local-first-github-pages.md). Это проще полной hexagonal architecture и предотвращает смешение браузерного UI с правилами и хранением при дальнейшем росте продукта.
