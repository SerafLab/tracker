# Выборочный просмотр скриншотов

Не открывать скриншоты автоматически после каждого прогона тестов. Просматривать их выборочно при изменениях интерфейса, диагностике конкретной визуальной ошибки или по запросу пользователя. Успешный прогон без изменений UI не требует просмотра PNG или отдельного визуального отчёта.

Выбирать экраны, размеры, языки и состояния по затронутому поведению. При изменениях адаптивной вёрстки проверить относящиеся к ним desktop/mobile-размеры; дополнительные изображения открывать для нерешённых вопросов. Явные визуальные критерии приёмки и запросы пользователя выполнять в заданной области. Не просматривать всю матрицу снимков по умолчанию.

В отчёте о визуальной проверке указать фактически просмотренные экраны, размеры, языки, состояния, результат и существенные ограничения. Успешные тесты и сохранённые PNG сами по себе не подтверждают визуальную проверку. Основной чат может использовать отчёт исполнителя без повторного открытия тех же снимков; повторный просмотр нужен при влияющих на отрисовку изменениях после интеграции, нерешённом замечании или запросе пользователя. Это правило не отменяет автоматические проверки и ответственность основного чата за итог.
