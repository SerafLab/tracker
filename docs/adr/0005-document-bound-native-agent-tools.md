# Native инструменты выбранного документа вместо stdio relay

После неуспешного production HTTPS→loopback WebSocket gate и успешного native marker-only эксперимента в Codex IAB пользователь 2 ноября 2026 года выбрал `document.modelContext` page tools обычного EasyTrack. Команды выполняются через публичный application API и транзакции существующей IndexedDB выбранного browser/tab/session; Node/stdio endpoint, pairing, серверная база и глобальная регистрация не вводятся. Это ограничивает поддержку совместимыми hosts и жизнью документа, но сохраняет storage origin и исключает неподтверждённый relay transport; история обоих экспериментов сохранена в [QA](../agents/mcp-browser-qa.md).

Session ID служит маршрутизации, а native platform/origin регулирует доступ без expanded exposedTo. Bounded in-memory ledger предотвращает повтор живой команды, но не обещает exactly-once после reload: потерянный после dispatch ответ требует проверки данных без автоматического replay. `update_card` намеренно принимает только name/flags и сохраняет актуальное description внутри общей транзакции отдельной attributes-командой; обязательный полный CardInput остаётся контрактом UI. Полные поля для внешнего update расширили бы объём правки и позволили бы затереть конкурентное описание устаревшей копией. Candidate, production task acceptance и пользовательский новый чат проверяются отдельно от marker feasibility и автоматизированных fixtures.
