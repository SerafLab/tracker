# Трекер личных проектов

Пет-проект для изучения полного цикла разработки с AI-инструментами и SDD на примере OpenSpec: от product discovery до опубликованных веб- и мобильных приложений.

Продукт помогает видеть этапы личных дел, сохранять договорённости и определять следующее действие. Первый проверочный сценарий — поиск квартиры.

## Текущее состояние

Завершены первоначальное product discovery и согласование технического плана веб-MVP. Зафиксированы основа React, TypeScript и Vite, публикация через GitHub Pages и GitHub Actions, хранение данных в IndexedDB, офлайн-обновления установленного приложения, автоматические проверки и процесс выпуска. Следующий шаг — описать первое небольшое изменение в OpenSpec; реализация приложения ещё не начата.

## Первая версия

Личное веб-приложение с несколькими проектами, досками статусов и карточками. Карточки содержат текст, ссылки, историю заметок и одно актуальное следующее действие с необязательной датой и временем.

После первоначальной загрузки приложение должно работать без интернета. В MVP предусмотрены ручная резервная копия и восстановление. Подробные границы и условия готовности описаны в vision.

Использование установленного приложения с телефона обязательно. Проверяются актуальный Chrome на компьютере, реальных iPhone и Android, а также Safari на реальном iPhone; фактические версии записываются для каждого выпуска.

## Подход к разработке

- GitHub — основной репозиторий и история проекта.
- Небольшие изменения с проверяемым поведением.
- Спецификации и предложения изменений хранятся в репозитории и ведутся с помощью OpenSpec.
- ADR создаются для значимых и труднообратимых технических решений.

Каркас OpenSpec добавлен; предложения изменений и спецификации ещё не созданы. Значимые технические решения фиксируются в `docs/adr/`. Документация описывает намерения и согласованные планы, а не реализованные возможности.
